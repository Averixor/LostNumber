Lost Number — Політика конфіденційності

Останнє оновлення: 26 липня 2026 року

Lost Number — офлайн-орієнтована логічна гра з числами. Ця політика пояснює, які дані обробляються на вашому пристрої.

1. Які дані ми збираємо

Ми не збираємо і не передаємо на сервери персональні дані, дані облікових записів, контакти, геолокацію або рекламні ідентифікатори.

Уся ігрова інформація зберігається локально на вашому пристрої:

  • прогрес рівнів, очки досвіду та інвентар бонусів;
  • досягнення, щоденні завдання й статистика;
  • налаштування мови, теми, звуку, музики та анімацій.

2. Де зберігаються дані

В Android-версії гри, створеній на Godot, дані зберігаються локально на пристрої у приватному каталозі застосунку. Збереження, налаштування та дані теми записуються у JSON-файли каталогу user://.

Ці дані не синхронізуються з хмарними сервісами та не передаються на наші сервери.

Очищення даних застосунку в налаштуваннях Android або перевстановлення гри призведе до втрати локального прогресу.

За вашим вибором гра може відкрити системний засіб вибору зображень для імпорту власного фону. Вибране зображення копіюється лише до приватного каталогу застосунку та нікуди не передається.

3. Мережа та дозволи

Поточна Android-версія гри не запитує дозвіл INTERNET. Для використання гри не потрібен обліковий запис, а ігровий прогрес не передається на наші сервери.

Екран зворотного зв’язку може відкрити зовнішній поштовий застосунок через системне посилання. Лист надсилається лише після явної дії користувача в цьому поштовому застосунку.

Ця сторінка політики конфіденційності опублікована на GitHub Pages як статична HTTPS-сторінка. GitHub може вести стандартні технічні журнали доступу до сторінки, однак ігрові дані через цей сайт не передаються.

4. Аналітика, реклама та платежі

У поточній версії гри немає сторонньої реклами, покупок у застосунку або сторонніх SDK аналітики, зокрема Firebase Analytics чи AdMob.

5. Діти та цільова аудиторія

Гра призначена для широкої аудиторії, зокрема для сімейного використання, але не орієнтована переважно на дітей. Ми свідомо не збираємо персональні дані користувачів, зокрема дітей.

6. Керування локальними даними

Ви можете видалити всі локальні дані гри, очистивши сховище застосунку в налаштуваннях Android: Налаштування → Застосунки → Lost Number → Сховище → Очистити дані . Дані також буде видалено після деінсталяції гри.

7. Зміни до політики

Ми можемо оновлювати цю політику у разі зміни функцій гри або способів обробки даних. Дату останнього оновлення зазначено на початку сторінки.

8. Контактна інформація

Privacy Policy

Lost Number is an offline-oriented number puzzle game. The app does not collect or transmit personal data to our servers.

Game progress, experience points, bonus inventory, achievements, daily tasks, statistics, and app settings are stored only on your device in the app's private storage, including user:// JSON files.

If you choose to import a custom background, the app may open Android's system image picker. The selected image is copied only to the app's private storage and is not uploaded or shared.

The current Android build does not request the INTERNET permission. The game does not require an account and does not send gameplay progress to our servers.

The feedback screen may open an external email application through a system link. An email is sent only after the user explicitly confirms the action in that application.

The current version contains no third-party advertising, in-app purchases, or third-party analytics SDKs such as Firebase Analytics or AdMob.

The app is intended for a general audience and is not primarily directed at children. We do not knowingly collect personal data from users, including children.

You can delete all locally stored data by clearing the app's storage in Android settings or by uninstalling the game.

This privacy policy is hosted as a static HTTPS page on GitHub Pages. GitHub may maintain standard technical access logs for this webpage, but no game data is transmitted through this website.
