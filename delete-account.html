Lost Number — Видалення акаунта

Розробник: Averixor

Останнє оновлення: 3 жовтня 2026 року

Як видалити акаунт у застосунку (найшвидше)

  1. Відкрийте Lost Number на Android.
  2. Перейдіть у Налаштування → Акаунт Google.
  3. Натисніть Видалити акаунт і підтвердіть.
  4. Якщо Firebase попросить повторний вхід — увійдіть через Google ще раз; після успішної re-auth видалення повториться автоматично.

Після успішного видалення локальна auth-сесія очищається одразу. Локальний прогрес гри на пристрої залишається (він не є хмарними даними акаунта).

Запит електронною поштою (якщо немає доступу до застосунку)

Надішліть запит на ryabinin.sergei.alekseevich@gmail.com або скористайтеся формою нижче (відкриє ваш поштовий застосунок).

Вкажіть Google email, яким ви входили в гру. Запити обробляються вручну: обліковий запис Firebase Auth буде видалено. Це не миттєва автоматика — зазвичай до 7 днів після отримання запиту (часто швидше).

Які дані видаляються

  • обліковий запис Firebase Auth (Google Sign-In) для Lost Number;
  • локальний кеш сесії входу в застосунку (auth_session.json) після in-app delete або після наступного запуску без акаунта.

У поточній версії немає Cloud Save / Firestore ігрового прогресу на серверах Averixor — окремих серверних ігрових збережень для видалення немає.

Які дані можуть залишитися і чому

  • Локальний прогрес гри на пристрої (рівні, XP, налаштування тощо) — зберігається локально і не прив’язаний до акаунта Google. Його можна видалити окремо: Android → Налаштування → Застосунки → Lost Number → Сховище → Очистити дані, або деінсталяцією.
  • Дані, які Google / Firebase зберігають як постачальник автентифікації, регулюються їхніми політиками; ми видаляємо запис користувача в проєкті Firebase Auth Lost Number.

Строки

  • У застосунку: видалення Firebase Auth user — одразу після успішного підтвердження (і re-auth, якщо потрібно).
  • Email-запит: ручна обробка, зазвичай до 7 днів.

Lost Number — Account deletion

Developer: Averixor

In app (fastest): Settings → Google account → Delete account. If Firebase requires a recent login, complete Google Sign-In; deletion retries automatically. Local game progress on the device remains (not cloud account data).

Email request: write to ryabinin.sergei.alekseevich@gmail.com with the Google email used to sign in. Requests are handled manually (not instant automation). Firebase Auth account deletion is typically completed within 7 days.

Deleted: Firebase Auth user for Lost Number; in-app auth session cache. Not cloud game saves in the current version (Cloud Save is not shipped). Device-local progress stays unless you clear app storage or uninstall.
